# SAPXG Tech Private Limited website

Responsive, static single-page website for SAPXG Tech Private Limited.

## Run locally

Open `index.html` directly, run `run.bat` (or `./serve.ps1`), or serve the folder with:

```powershell
# Option 1: Native Windows runner (no Python required)
.\serve.ps1

# Option 2: Python (if installed)
python -m http.server 8000
```

Then visit `http://localhost:8000`.

The contact form currently demonstrates the front-end success state. Connect it to the company email or CRM before production launch.
